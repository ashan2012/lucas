模块以 `cli.py` 为入口（`__main__.py` 转发到 `main()`），采用清晰的自上而下分层：
- CLI 层 (`cli.py`)：使用 `argparse` 解析参数，负责输入校验、错误码返回以及调用 pipeline。
- 管线层 (`pipeline.py`)：编排端到端流程——从图片/JSON 读取 → `layout.parse_card` 结构化 → `pinyin_util.analyse` 补全拼音 → `strokes.prefetch/get` 拉取笔顺 → `draw.PageRenderer` 渲染 → `export` 落盘；对外暴露 `BuildOptions` / `BuildResult` / `CardMeta` 三个 dataclass。
- 能力层（平铺子模块）：`ocr.py` 封装 macOS Vision OCR（编译 `swift/vision_ocr.swift` 二进制）、`layout.py` 基于 OCR 框聚类行并按行列配对 hanzi/pinyin、`strokes.py` 负责从 hanzi-writer-data CDN 缓存 SVG 笔画路径、`draw.py` 用 PIL 绘制田字格、`fonts.py` 管理字体、`pinyin_util.py` 做拼音切分、`export.py` 统一输出 PNG/PDF/HTML/JSON。
- 配置层 (`config.py`)：集中定义 `CACHE_DIR`、`STROKE_SOURCES`、画布尺寸常量等。
依赖方向单向向下：CLI → pipeline → {ocr, layout, strokes, draw, export}，各能力模块仅反向依赖 `config`，无环。
