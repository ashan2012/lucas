### 拼读小卡片
- 定义：本项目输入的业务对象：小学生用的练习卡片，版面包含标题、课次标记、若干行「拼音 + 汉字」词语对以及页脚「我读了（ ）遍」。程序的目标是将这种卡片照片自动还原为词语表，并为每个汉字生成练习页。
- 别名：卡片、小卡片

### 田字格
- 定义：用于书写练习的方格，内部有十字辅助线。本项目的渲染目标：每个汉字在田字格中展示笔顺描红，随后留出空白田字格供学生临摹。

### 笔顺
- 定义：汉字书写的笔画顺序。本项目为每个汉字提供逐笔演示（第 n 格含前 n 笔，最新一笔标红）、编号全图以及描红/练习行。
- 别名：笔画顺序

### 词语页
- 定义：每张卡片对应一个词语的输出页面，顶部显示词语、拼音和卡片标题，下方依次排列逐笔条、编号格和空白练习格。重复汉字在同一页只画一次。
- 别名：word page

### 单字页
- 定义：每个不重复汉字单独输出一张强化练习页，包含笔顺条、浅灰字帖描红和空白练习行，存放于 `out/<卡片名>/chars/` 目录。
- 别名：character page

### 总览页
- 定义：输出的第一张页面（`00_cover.png`），汇总整张卡片的全部词语及其拼音，便于对答案。
- 别名：cover page

### parsed.json
- 定义：OCR 识别结果的中间产物，包含 `title`、`subtitle`、`words`（每项含 `hanzi`、`pinyin`、`pinyin_ocr`）字段。用户可手工修改后以 `--from-json` 重新渲染，跳过 OCR 阶段。
- 别名：识别结果

### 行聚类
- 定义：layout.py 的核心算法：将 OCR 返回的文本行按其垂直中心聚类成行，再用多数票判定每行是「拼音行」还是「汉字行」，并把每个汉字行与其紧邻上方的拼音行配对。
- 别名：版面还原、行分类

### 逐笔条
- 定义：词语页上的笔顺演示区域：从左到右的格子中，第 n 格累积显示前 n 笔，最新一笔用红色高亮，直观展示起笔与收笔方向。

### 编号格
- 定义：词语页上叠加了灰色字形和红色笔顺编号的练习格。编号位置沿笔画切向/法向试探避让，避免密笔字互相遮挡。
